Tinnitus fNIRS auditory cortex study
====================================

Functional near-infrared spectroscopy (fNIRS) recordings of human auditory cortex in participants with subjective tinnitus and controls, acquired with a NIRx NIRSport2 system.

Groups are recorded in participants.tsv:
  control      -> participant IDs sub-0xx
  experimental -> participant IDs sub-1xx
The original_label column maps each participant to the source folder.
